# Images Directory

This directory contains all image assets for the portfolio site.

## Structure

- **gameboard/** - Images and media for the Interactive Gameboard project
- **spare-shed/** - Images and media for The Spare Shed project

## Usage

Reference images in HTML using relative paths:
- From project pages: `../images/[project-name]/[image-file]`
- From index.html: `images/[project-name]/[image-file]`

## Recommended Image Formats

- **Photos/Screenshots**: JPEG (.jpg) or WebP for better compression
- **Diagrams/Icons**: PNG (.png) or SVG (.svg)
- **Videos**: MP4 (.mp4) or WebM (.webm)

## Best Practices

1. Use descriptive filenames (e.g., `gameboard-hexagon-tiles.jpg`)
2. Optimize images before uploading (compress, resize appropriately)
3. Keep file sizes reasonable for web performance
4. Use consistent naming conventions (lowercase, hyphens instead of spaces)
